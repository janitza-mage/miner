Texture Image: Array von Texels

Sampler: Zugriff eines Shaders auf eine Texture

"""
Sampler and texture objects may be bound together so that the sampler object state is used by shaders when sampling

"""


Terminologie:
- Pixel Rectangle
- Texture Image
    1-, 2- oder 3-dimensionales Texel-Array
    "Each image consists of one or more layers."
- Texture
    können 1..3-dimensional sein und dann sind ihre Texture Images es auch
    "One- and two-dimensional array textures are arrays of one- or two-dimensional images."
- 2d Multisample Texture: 2d Texture mit mehreren Samples pro Texel
- 2d Multisample Array Texture: 2d Array Texture mit mehreren Samples pro Texel
- Layer
- Sampler
- Internal Format
- Internal Data Type
- Cube map: special two-dimensional array texture with six layers that represent the faces of a cube.
